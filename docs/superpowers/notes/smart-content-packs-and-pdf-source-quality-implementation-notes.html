Smart Content Packs And PDF Source Quality Implementation Notes

Running notes for PDF text extraction, Markdown-ish PDF normalization, content packs, Codex pack handoff, OpenAI pack generation, and later LLM pack planning. Future worker tasks should append entries when behavior diverges from or interprets the approved spec.

Design Decisions

2026-05-27 planning

The execution plan starts with PDF source quality before content packs. Content packs become much more useful once papers and PDF-only sources can produce source-backed packet content without manual rereading.

2026-05-27 planning

PDF work stays in internal/source with a new pdf.go file. The plan avoids a separate internal/source/pdf package until there is real pressure from multiple extractor engines or broader reuse.

2026-05-27 planning

Pack planning gets its own narrow internal/pack package and a separate content-pack.json artifact. visual-packet.json remains the source-backed story spine instead of becoming a multi-output container.

Deviations

2026-05-27 planning

No approved deviation yet. The plan keeps --backend codex rejected and treats Codex image generation as a manual handoff workflow.

Tradeoffs

2026-05-27 planning

Poppler pdftotext is the stable first extractor. This gives the smoothest local experience when installed and avoids shipping native libraries, at the cost of requiring clear install guidance when Poppler is missing.

2026-05-27 planning

The first pack targets are fixed and deterministic. This gives repeatable tests and a dependable CLI contract before adding an LLM planner that can revise the same schema.

2026-05-27 subagent audit

The plan intentionally replaces the existing PDF test that accepts warning-only behavior. Warning-only PDF support is now treated as the root product gap, not as an acceptable fallback for PDF-only sources.

2026-05-27 subagent audit

Content pack image paths stay out of manifest.output_files until files exist. Planned image paths live in content-pack.json so the manifest does not claim outputs that were not generated.
