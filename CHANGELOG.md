# Changelog

## 0.1.0 - 2026-05-25

- Added the first public release candidate for `visualize`.
- Added GitHub repo, docs URL, Markdown, PDF, JSON packet, and local repo source resolution.
- Added bounded source gathering with symlink, secret-like file, generated directory, binary, and file-size safety checks.
- Added source-backed visual packet generation, HTML scaffold output, fallback PNG rendering, manifest output, and bundle validation.
- Added local, OpenAI, auto, and hybrid backend selection with local as the privacy-preserving default.
- Added `visualize doctor` and `visualize --version`.
- Added OSS release docs, scripts, and GitHub Actions workflows.
